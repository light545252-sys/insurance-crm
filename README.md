## 系統概覽

專為保險業務設計的行動 CRM，以 PWA 形式運行，可加入手機主畫面像 App 一樣使用。所有資料儲存在 Notion，網頁只作為操作介面。

```
手機瀏覽器
    ↓
index.html（PWA 介面）
    ↓
Cloudflare Workers Proxy（處理 CORS）
    https://notion-proxy.light545252.workers.dev
    ↓
Notion API
    ↓
Notion 資料庫（「亮」工作空間）
```

## 功能頁面（底部導覽 6 個 Tab）

### 🏠 首頁
- 今日記錄數、本週拜訪數、活躍客戶總數
- 快速記錄按鈕（7 種操作）
- 最近拜訪記錄列表

### 📅 行事曆
顯示前一天到未來 6 天（共 7 天），整合 5 個資料來源：

| 顏色 | 來源 | Notion 欄位 | 備註 |
|------|------|------------|------|
| 🟢 綠點 | 拜訪記錄 | 拜訪日期 | |
| 🟡 黃點 | 拜訪記錄 | 下次跟進日期 | 有時間時顯示 ⏰ |
| 🔵 藍點 | 每日任務 | 日期 | 未完成才顯示 |
| 🟣 紫點 | 待辦清單 | 預計完成日 | 未完成才顯示 |
| 🔴 紅點 | 理賠記錄 | 狀態更新日期 | 得知/送件/醫療中/理賠中 才顯示 |

逾期未完成項目自動顯示在今天最前面，標示延滯天數。

### 📝 待辦清單
- 顯示 `DB.todos` 全部待辦
- 篩選：全部 / 未完成 / ⚠️ 逾期 / ✅ 已完成
- 依日期排序，逾期優先
- 點擊可標記完成或延後追蹤

### 👥 客戶
- 顯示 `DB.clients` 全部客戶（分頁撈取，無 100 筆限制）
- 即時搜尋姓名
- 狀態標籤：潛在客戶 / 現有客戶

### 🏥 理賠
- 顯示 `DB.claims` 全部理賠記錄
- 篩選：全部 / 進行中 / 已理賠 / 結案
- 依進度排序（理賠中→醫療中→送件→得知→已理賠→結案）
- 點擊查看詳情、直接更新進度與實際理賠金額

### ⚙️ 設定
- 填入 Notion Integration Token
- PWA 安裝說明
- 資料庫 ID 快查

## 快速記錄（Sheet 操作）

### 💬 關係維護 → 拜訪記錄 + 每日任務
### 🤝 轉介紹鋪墊 → 拜訪記錄 + 每日任務
### 🎯 新觸點開發 → 每日任務（可選建立客戶）
### 📋 保單說明 → 拜訪記錄 + 預估試算表 + 每日任務
### ✅ 成交確認 → 預估試算表 + 客戶資料庫 + 佣金明細 + 拜訪記錄

成交後自動執行：
- 預估試算表 → `🖊️ 已簽約待核保`
- 客戶狀態 → `現有客戶`
- 佣金明細 → 新增一筆（含今日簽約日期）

### 📝 新增待辦 → 待辦清單（有關聯客戶時同步寫拜訪跟進日期）

### 🏥 新增理賠 → 理賠記錄

| 欄位 | 說明 |
|------|------|
| 客戶 | Relation 關聯 |
| 服務項目 | 案件名稱（必填） |
| 理賠原因 | 事故/病因（語音支援） |
| 保險公司 | 自由輸入 |
| 險種 | 多選（壽險/意外險/醫療險/車險/旅平險/癌症險） |
| 理賠進度 | 見下方選項 |
| 預估理賠金額 | 數字 |
| 約簽文件日期 | datetime-local（選填） |
| 狀態更新日期 | datetime-local，開啟自動帶入現在時間 |
| 相關資料連結 | Google Drive 等連結 |
| 備註 | 語音支援 |

| 進度 | 顏色 | 說明 |

## 日期時間系統

所有日期欄位統一使用 `datetime-local`，支援精確到分鐘的時間記錄。

### Helper 函數

```javascript
// 現在時間 → datetime-local 格式
nowDTLocal() → "2026-06-03T14:30"

// input 值 → Notion date 物件（自動帶台灣時區 +08:00）
toNotionDate("2026-06-03T14:30") → { start: "2026-06-03T14:30:00+08:00" }
toNotionDate("2026-06-03")       → { start: "2026-06-03" }
```

### Sheet 開啟自動填入現在時間

| Sheet | 自動填入欄位 |
|-------|------------|
| 關係維護 | 下次跟進日期與時間 |
| 轉介紹鋪墊 | 下次跟進日期與時間 |
| 保單說明 | 下次跟進日期與時間 |
| 成交確認 | 下次跟進日期與時間 |
| 新增理賠 | 狀態更新日期 |

所有欄位皆為選填，清空即可不填。
